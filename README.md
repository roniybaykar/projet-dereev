# Projet DEREEV - Détection des Réévaluations

## Contexte
Projet réalisé en collaboration avec l'Hôpital Foch. L'objectif est d'utiliser des techniques de NLP pour automatiser la détection des réévaluations d'antibiotique dans des notes médicales. 

## Installation
### Environnement virtuel et dépendances
```
python -m venv venv 
source venv/bin/activate 
pip install -r requirements.txt
```
